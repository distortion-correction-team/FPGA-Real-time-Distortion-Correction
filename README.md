# FPGA-Real-time-Distortion-Correction
基于紫光同创PG2L100H-6IFBG676的任意角度实时畸变矫正系统
#  广角畸变与姿态矫正系统

面向广角镜头的**几何畸变 + 相机姿态倾斜**双重失真，在紫光同创 FPGA 上实现全流水、参数化、可在线切换的实时矫正。

以 OV5640 为图像源，经 DDR3 帧缓冲后，在读出通路上串联 **自动白平衡 → 低照度降饱和 → 畸变矫正 + 三轴旋转 → 自适应 Gamma** 四级处理，最终以 1280×720@30 Hz 经 HDMI 输出。

（技术文档请看[[无畸视界 · 任意角度实时矫正]]）
## 功能特性

| 功能 | 说明 |
|---|---|
| **几何畸变矫正** | Brown–Conrady 五项模型（k1/k2/k3/p1/p2），反向映射免求逆 |
| **三轴姿态校正** | Roll / Pitch / Yaw 仿射旋转，单 CORDIC 时分复用 |
| **自动白平衡** | 帧统计 + 倒数查表 + 增益限幅 [0.5×, 2.5×] |
| **低照度降饱和** | `X' = Y + k(X−Y)`，k 随亮度自适应 |
| **自适应 Gamma** | γ=1.0 ⇄ γ=1/2.2 按亮度统计自动切换 |
| **全参数在线可配** | 5 类参数经单路 UART 下发，帧边界原子生效，**无需重新综合** |
| **三档运行时门控** | 全处理 / 去除畸变 / 原始画面，等长延迟旁路，秒级切换不撕裂 |

## 系统架构

```
OV5640 ──► 8→16 位拼接 ──► 帧缓冲写入 ──► DDR3 ──► 帧缓冲读出
                                                      │
                     ┌────────────────────────────────┘
                     ▼
        ① 自动白平衡 (3 拍) ──► ② 低照度降饱和
                     │
                     ▼
        ③ 畸变矫正 + 三轴旋转 (19 拍)
             畸变 8 + 旋转 6 + 行窗口 2 + 双线性插值 3
                     │
                     ▼
        ④ 自适应 Gamma (1 拍) ──► 输出寄存器 (1 拍) ──► HDMI
```

**矫正模块内部（双通路）**

```
坐标通路：8 + 6 + 2 = 16 拍 ──┐
                              ├─► 双线性插值 (3 拍) ──► 19 拍
像素通路：16 拍同步延迟 ──────┘
```

## 串口协议

115200 bps，8N1。帧格式：

```
0xAA | CMD | payload | XOR | 0x55
XOR = 0xAA ⊕ CMD ⊕ payload
```

| CMD    | 内容                     | 帧长    |
| ------ | ---------------------- | ----- |
| `0x02` | 门控标志（两级）               | 5 字节  |
| `0x03` | 缩放系数                   | 6 字节  |
| `0x04` | 五项畸变系数                 | 24 字节 |
| `0x05` | 相机内参（fx/fy/cx/cy + 倒数） | 20 字节 |
| `0x06` | 三轴欧拉角（Q16.16 弧度）+ 缩放   | 18 字节 |

## 三档显示模式

| 档位         | 通路                    | 延迟   |
| ---------- | --------------------- | ---- |
| **① 全处理**  | 白平衡 → 畸变 + 旋转 → Gamma | 23 拍 |
| **② 去除畸变** | 白平衡 → 旁路矫正 → Gamma    | 23 拍 |
| **③ 原始画面** | 旁路全部处理                | 23 拍 |

三条通路延迟严格相等，切换瞬间画面不错位。

## 快速开始

1. 用 PDS 打开工程，确认综合与布局布线通过（`All Constraints Met`）
2. 连接 JTAG，下载 `.sbit` 到 Flash 或直接下载
3. 等待 `ddr_init_done` 与 HDMI 画面稳定
4. 按 K2 切换三档模式，验证画面切换不错位
5. 用串口工具（115200 8N1）下发参数帧，观察画面实时响应

## 已知限制

| 限制                         | 原因                           |
| -------------------------- | ---------------------------- |
| 可转角度上限 **±5.74°**（128 行窗口） | 行扫描架构：`sinψ ≤ ROWS/W`，物理约束   |
| 大畸变系数下边缘出现深灰（模拟暗角）         | 采样越界，已填充而非回卷                 |
| 端到端延迟为 33.3~66.7 ms 区间     | 读侧时序由 `sync_vg` 自由产生，与写侧相位异步 |
| 输出 720p30，非 1080p          | 受 DDR 带宽与行缓存深度限制             |

## 设计要点

- **反向映射**：遍历输出理想坐标，正向求采样点，回避畸变模型无解析反函数
- **二维奇偶 4-bank 拆分**：2×2 邻域四个采样点各占一个 bank，从架构上消除块 RAM 复制（DRAM 139.5 → 44）
- **等长延迟旁路**：19 / 23 拍严格对齐，保证门控切换不撕裂
- **单 CORDIC 时分复用**：三轴交错流水 + 36 bit 相位标签，LUT 4,600 → 1,533
- **帧边界原子生效**：全部参数在 `vsync` 沿锁存，帧内恒定
